# 下载完成后动作

设置 → 下载完成后。所有自动打开、扫描、完成窗口、退出和关机默认关闭；通知声音也默认关闭。

## 每个文件

HTTP 文件和媒体任务都在新完成事件后执行；启动恢复的已完成历史不会重放。可选择不打开、打开所在目录或打开文件；打开文件会使用系统关联程序，包括可执行文件。

扫描程序使用绝对路径，参数每行一个，`{file}` 替换为完整文件路径。不会把参数交给 shell，也不会按空格重新拆分。扫描退出码必须为 0 才会继续打开；超时、取消、程序无法启动或文件被隔离都会显示错误。扫描器输出不写入日志，避免包含敏感文件内容。

动作运行于有界工作线程。底部显示处理状态，点击可以停止尚未完成的扫描和后续打开动作。取消或超时会终止并回收直接启动的扫描进程；扫描器自己创建的独立进程不由 Swoop 管理。正常退出会先请求取消并等待工作线程完成。

完成窗口在扫描成功后显示文件名和打开入口；文件不存在、变成目录或符号链接时拒绝执行文件动作。Swoop 不把自定义扫描器的退出码等同于保证文件安全。

## 全部下载成功

支持退出 Swoop 或向系统请求关机，倒计时可配置为 10–3600 秒。倒计时开始时唤回窗口，关闭倒计时窗口或点击取消均取消本次动作。

必须有本次运行的新完成事件才会触发；HTTP/媒体的等待、暂停、失败，以及正在抓取或未成功完成的站点项目，都会阻止倒计时。新工作加入后重新等待完整的倒计时；扫描失败也会阻止自动动作。处理失败原因后可重新保存完成动作设置，重新武装仍需后续完成事件。已有历史失败项可以手动继续或移除记录。

macOS 通过系统事件请求正常关机，系统可能要求自动化权限或因未保存文档拒绝；Windows 使用 `shutdown.exe /s /t 0`。倒计时位于 Swoop 内，不添加强制关闭参数。根据 [Microsoft shutdown 文档](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/shutdown/)，非零系统 `/t` 会隐含 `/f`，因此未将应用倒计时传入系统命令。

## 验证边界

策略、持久化、参数边界、扫描失败阻止打开、超时回收及运行中取消使用本地受控进程测试。测试不会打开真实下载文件，不会执行系统关机，也不会修改本机开机项。macOS/Windows 的真实文件关联程序、杀毒软件、声音和系统关机交互保留原生验收项。
