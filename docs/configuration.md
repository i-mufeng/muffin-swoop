# 配置入口与默认行为

桌面设置保存在当前用户 SQLite 数据目录；媒体任务、站点项目各自保存选择。`SWOOP_DATA_DIR` 可隔离测试数据。密码不作为普通配置导出：站点与代理登录使用会话内存或系统凭据库；浏览器普通文件下载交接的请求头仍按既有任务契约存入数据库。

| 入口 | 可配置项 | 默认 / 生效范围 |
| --- | --- | --- |
| 设置 → 同名文件 | 询问、覆盖、重命名、跳过 | **询问**；文件与媒体共用。单次选择可记住，失败/取消保留原件 |
| 设置 → 下载 | 目录、连接数、自动续传、批量上限、限速、进度提示 | 8 连接；连接数在新建或暂停后继续时应用。进度提示默认为屏幕右下角的下载卡片（完成后原地变为完成卡片，8 秒后收起），可换成居中进度窗口或关闭 |
| 设置 → 外观 / 语言 | 深浅主题、进度样式、中文/English | 中文；保存后立即切换，重启保留，托盘菜单同步刷新 |
| 列表与工具栏 | 卡片/表格、列显示/顺序/宽度、按钮显示/顺序 | 改动立即保存 |
| 设置 → 拖放 | 拖入链接/文件、拖出已完成文件 | 都开启；拖入预填确认，拖出为复制，不移走原文件 |
| 设置 → 站点认证 | 精确来源、认证协议、账号、保存位置 | 凭据默认仅当前会话；系统账户或系统凭据库显式选择 |
| 网络 / FTP | 代理与认证、凭据保存、排除、超时、重试、TLS、FTP 连接方式 | 代理认证关闭；普通 HTTP(S) 凭据默认仅当前会话；显式代理失败不退回直连；FTP 登录仅当前会话 |
| 队列 / 配额 | 并发、顺序、计划、同步周期、时段字节额度 | 配置与用量保留；媒体/抓取使用各自预算 |
| 分类 | 扩展名、域名、目录与优先顺序 | 自动分目录关闭；用户启用后用于新任务 |
| 媒体下载 → 设置 | FFmpeg、并发、清单预算、质量/音轨、直播时长/刷新间隔、重试、MMS 传输、缓存目录/容量 | 字幕默认关闭，直播刷新 250 毫秒，MMS 默认 HTTP；缓存只复用经过来源验证的完整片段 |
| 站点抓取 | 资源类型、URL 排除、深度/数量/预算、重定向、robots、脚本保留 | robots 开启，动态浏览器渲染关闭；配置随项目保存 |
| 站点抓取 → 动态页面 | 浏览器路径、首页/所有页面、虚拟时间、超时、DOM/网络预算 | 显式指定本机浏览器；不使用已有用户 profile |
| 通知 / 完成动作 | 完成/失败、声音、时机、扫描、打开、完成窗口、退出/关机 | 默认后台通知，声音和完成动作关闭 |
| 系统集成 | 关窗驻留、剪贴板、登录启动、浏览器桥接端口/确认模式 | 登录启动关闭；变更由用户显式操作 |
| 设置 → 软件更新 | 更新源、公钥、通道、自动检查、间隔 | 自动检查关闭，源/公钥为空；默认稳定通道、168 小时；安装需点击确认 |
| 扩展选项 | 接管、域名/扩展名过滤、媒体检测/缓存、批量并发、语言 | 与桌面独立保存；语言可在扩展选项切换 |

语言只影响界面文案；任务 ID、设置键、协议字段、路径及用户输入不会随语言改变。已保存的分类名等用户内容保留原文；服务器、FFmpeg 和底层库诊断保留来源语言。CLI 帮助当前使用中文。

完整行为与限制见 [同名处理](file-conflicts.md)、[媒体](../crates/media/README.md)、[抓取](grabber.md)、[站点认证](site-auth.md)、[代理认证](proxy-auth.md)、[拖放](drag-drop.md)、[更新](updates.md)。
